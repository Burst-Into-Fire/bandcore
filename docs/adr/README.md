# Architecture Decision Records

Each ADR records one significant decision: its context, the alternatives and the consequences. Format: [MADR](https://adr.github.io/madr/), see [template.md](template.md).

- Write a new ADR when a decision is hard to reverse or affects several modules.
- Never rewrite an accepted ADR. To change a decision, write a new ADR and mark the old one as *Superseded*.
- *Proposed* means the decision depends on an open point listed in the [roadmap](../roadmap.md#open-points-with-the-requirements-docs) and must be confirmed before the affected issues start.
